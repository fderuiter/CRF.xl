## 2024-05-23 - [AuthoringView Feedback] Learning: Standalone `Excel.run()` operations like Smart Macros bypass global app processing states. They require explicit local React state management to provide user feedback (loading spinners) and disable buttons, preventing overlapping document edits in the embedded WebView2 environment. Action: Always wrap standalone `Excel.run()` commands in local `try/finally` blocks setting state to manage loading UI and disabled states.
